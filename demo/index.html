Validação do USHub no seu Android

Esta página roda o ushub.user.js real do repositório, com GM_* emulados. O botão flutuante </> no canto da tela é o produto.

Checklist (≈1 min) — fecha a USH-02

  1. Arraste o botão para a esquerda/direita → solte: encaixa na borda; espere ~4s parado: fica translúcido.
  2. Toque no campo abaixo e abra o teclado → o botão some; feche o teclado → volta.
  3. Abra o painel (toque no botão) → catálogo de fábrica lista 3 scripts sem configurar nada.
  4. Busque noturno (sem acento) → 1 resultado; tente acentuar com o Gboard (composição não pode travar).
  5. Ajustes → alterne Escuro/Claro e A−/A+ → recarregue a página → preferências persistem.
  6. Toque Instalar num script → abre o código cru (aqui é texto — no Firefox+Tampermonkey vira a tela de instalação).

Conteúdo para testar "botão na frente do texto"

Texto propositalmente longo para rolagem. O botão, parado, recua em translucidez para não competir com o conteúdo — e pode ser arrastado para onde não atrapalhe.
